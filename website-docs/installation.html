Installation & Quick Start

From zero project to running API in a few steps.

Requirements

  • Go 1.25+
  • Optional: Redis for sessions/cache/queue
  • Optional: Postgres/MySQL/SQL Server (SQLite supported by default)

1. Install the CLI

go install github.com/shashiranjanraj/kashvi/cmd/kashvi@latest
kashvi --help

If you are inside the framework repo itself, you can also run make install.

2. Create a Project

mkdir my-app
cd my-app
go mod init my-app
go get github.com/shashiranjanraj/kashvi

Create main.go:

package main

import (
  "github.com/shashiranjanraj/kashvi/pkg/app"
  appctx "github.com/shashiranjanraj/kashvi/pkg/ctx"
  "github.com/shashiranjanraj/kashvi/pkg/router"
)

func main() {
  app.New().
    Routes(func(r *router.Router) {
      r.Get("/health", "health", appctx.Wrap(func(c *appctx.Context) {
        c.Success(map[string]any{"ok": true})
      }))
    }).
    Run()
}

3. Add Environment Configuration

APP_ENV=local
APP_PORT=8080
JWT_SECRET=replace-with-long-random-secret

DB_DRIVER=sqlite
DATABASE_DSN=kashvi.db

REDIS_ADDR=localhost:6379
REDIS_PASSWORD=

DB_DRIVER supports sqlite, postgres, mysql, sqlserver.

4. Run and Verify

kashvi serve
curl http://localhost:8080/health
kashvi route:list

In project mode, the CLI delegates to your app entrypoint: go run . serve.

5. Generate First Resource

kashvi make:crud Post
kashvi migrate
kashvi serve
