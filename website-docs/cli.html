CLI Reference

Operational and scaffolding commands for Kashvi projects.

Server Commands

CommandPurpose
kashvi runStart HTTP server (alias for serve; delegates to project entrypoint).
kashvi serveStart HTTP server.
kashvi buildBuild binary output as ./kashvi.
kashvi route:listList all registered named routes.
kashvi grpc:serveRun gRPC server only.

Database Commands

kashvi migrate
kashvi migrate:rollback
kashvi migrate:status
kashvi seed

Workers

kashvi queue:work           # default: 5 workers
kashvi queue:work -w 10
kashvi schedule:run

Scaffold Commands

kashvi make:resource Post
kashvi make:crud Post       # alias
kashvi make:model Comment
kashvi make:controller Auth
kashvi make:service BillingService
kashvi make:migration add_tags_to_posts
kashvi make:seeder PostSeeder

Scaffold commands do not overwrite existing files. Customize templates with .kashvi/stubs/*.stub.

Common Flow

kashvi make:crud Post
kashvi migrate
kashvi serve
kashvi route:list
