CRUD Walkthrough

Scaffold a full resource, wire routes, run migrations, and validate endpoints.

1. Scaffold

kashvi make:crud Post
# optional flags
kashvi make:crud Post --authorize --cache
  • --authorize: generated route snippet includes auth middleware placeholder.
  • --cache: generated controller includes caching TODO blocks.

2. Generated Files

  • app/models/post.go
  • app/controllers/post_controller.go
  • app/services/post_service.go
  • database/migrations/<timestamp>_create_posts_table.go
  • database/seeders/post_seeder.go
  • testdata/post_scenarios.json

3. Register Routes

func RegisterAPI(r *router.Router) {
  api := r.Group("/api")

  ctrl := controllers.NewPostController()
  api.Get("/posts", "posts.index", appctx.Wrap(ctrl.Index))
  api.Post("/posts", "posts.store", appctx.Wrap(ctrl.Store))
  api.Get("/posts/{id}", "posts.show", appctx.Wrap(ctrl.Show))
  api.Put("/posts/{id}", "posts.update", appctx.Wrap(ctrl.Update))
  api.Delete("/posts/{id}", "posts.destroy", appctx.Wrap(ctrl.Destroy))
}

Attach routes in main.go with app.New().Routes(routes.RegisterAPI).Run().

4. Fill Migration and Run

The generated migration registers itself but starts as a placeholder. Implement Up and Down, then run:

kashvi migrate
kashvi migrate:status

5. Test Endpoints

# create
curl -X POST http://localhost:8080/api/posts \
  -H 'Content-Type: application/json' \
  -d '{}'

# list
curl http://localhost:8080/api/posts

# show
curl http://localhost:8080/api/posts/1

# update
curl -X PUT http://localhost:8080/api/posts/1 \
  -H 'Content-Type: application/json' \
  -d '{}'

# delete (204)
curl -X DELETE http://localhost:8080/api/posts/1 -i

6. Scenario-Based Test Data

The generator creates testdata/post_scenarios.json. Use it with your TestKit runner so documentation and tests stay aligned.
